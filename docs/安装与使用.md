# 安装与使用

用 Codex、Claude Code 等 agent 安装更省事：把 [README](../README.md#用-agent-安装推荐) 里那段话发给它即可，它会按仓库根目录的 [AGENTS.md](../AGENTS.md) 操作。下面是手动步骤。

## 1. 编译安装

Ubuntu 22.04 / 24.04：

```sh
sudo apt install build-essential cmake libfcitx5core-dev file qemu-user-static e2fsprogs unzip \
  python3 python3-cryptography libsnappy1v5 openssl curl
bash scripts/prepare_ndk.sh
export ANDROID_NDK_HOME="$PWD/.deps/tools/android-ndk-r27c"
bash scripts/e2_img.sh
./WeTypeIME-Engine-x86_64.AppImage install --user
```

- 第一次编译会下载 Android NDK 和 AOSP 运行时，之后会复用缓存。
- `install` 会从官方服务器下载微信输入法 3.5.4 APK（约 214 MB）并校验。已经下载过的话，可以加 `--apk 文件路径`。
- 没有 FUSE 时，先设置 `APPIMAGE_EXTRACT_AND_RUN=1`。

装好后重启 Fcitx5，在输入法设置里添加“微信拼音”。到这一步，本地输入就能用了。

## 2. 关联手机或电脑（可选）

需要用到 [wxc](https://github.com/mkdir700/wx-ime-sdk) 和 Node.js 22 以上版本。

```sh
npm install --prefix "$HOME/.local/share/wetype-ime/tools" @mkdir700/wxc@0.1.0
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py pair --name "Linux 输入法"
```

在手机或 Mac 的微信输入法里打开“关联设备”，取得六位关联码，在终端里输入，再回到官方客户端确认。关联成功后，启用云功能：

```sh
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py enable --timer
```

重启 Fcitx5 后生效。`--timer` 会装一个每 5 分钟运行一次的用户定时任务，用来续期登录、刷新设备组信息和常用语，不会读写词库。词库同步由引擎在你打字时自己进行。

需要补齐关联前的历史学习数据时，按[恢复历史词库](恢复历史词库.md)检查快照、在隔离副本导入并补齐缺失词条。

设备身份默认保存在 `~/.local/state/wetype-ime/account`。不要把它放进 git 仓库或网盘，也不要在多台机器上共用。

### 单独启用剪贴板互通

剪贴板默认关闭。已关联设备后，在官方客户端打开跨设备复制粘贴，再从 Linux 图形桌面的终端执行：

```sh
# X11 安装 xclip；Wayland 安装 wl-clipboard
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py clipboard enable
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py clipboard status
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py clipboard disable
```

启用期间，新复制的纯文本会发给微信输入法服务器，远端文本会写进 Linux 系统剪贴板。首次启动不上传已有文字；图片和文件不参与同步，超过 256 KiB 的文本只接收不发送。不需要重启 Fcitx5。依赖、桌面兼容性和冲突规则见[剪贴板互通](剪贴板互通.md)。

## 3. 日常使用

### 全拼与小鹤双拼

默认使用全拼。打开 `fcitx5-configtool`，在输入法列表中选中“微信拼音”，点击
配置按钮，将“拼音方案”设为“全拼”或“小鹤双拼”并应用。

小鹤输入 `nihc` 出“你好”，`vsgo` 出“中国”；预编辑每两键分段，例如 `ni hc`。
方案保存在 `~/.config/fcitx5/conf/wetype.conf`，重启后保留。应用时插件会重启自己的
引擎会话；切换前先完成输入，尚未完成的编码会作为原始文本上屏。

命令行演示跟随这个设置，也可用 `WETYPE_DOUBLE_PIN=0` 临时选择全拼。
其他双拼方案尚未加入图形设置。

### 拼音显示位置

默认在候选窗中显示拼音。打开 `fcitx5-configtool`，选中“微信拼音”并点击配置按钮，
勾选“在输入框中显示拼音”后，拼音会以未上屏文本显示在当前应用的输入框里，候选窗只显示候选词。
选词、回车或 Esc 后，输入框中的拼音会随输入状态更新。取消勾选即可恢复默认显示位置。
设置保存后立即生效，重启后保留。如果应用不支持输入框内的预编辑文本，拼音仍显示在候选窗中。

在输入框中显示拼音时，候选框停在本轮输入的第一个字母处，不会随着拼音变长向右移动，
不影响选词、退格或上屏。

### 模糊音设置

微信输入法官方引擎原生支持全部 19 组模糊音。打开 `fcitx5-configtool`，在“微信拼音”配置中可独立勾选需要的模糊音（设置保存在 `~/.config/fcitx5/conf/wetype.conf`，勾选后自动重启引擎生效）：

- **声母模糊音**：`z = zh`、`c = ch`、`s = sh`、`n = l`、`h = f`、`r = l`、`g = k`
- **韵母与音节模糊音**：`an = ang`、`en = eng`、`in = ing`、`ian = iang`、`uan = uang`、`on = ong`、`eng = ong`、`un = ong`、`un = iong`、`an = ai`、`hui = fei`、`huang = wang`

在命令行或测试脚本中，也可通过环境变量 `WETYPE_FUZZY` 直接开启（支持如 `s_sh,n_l`，或十六进制/十进制数字掩码）。

### 常用按键

| 按键 | 作用 |
|---|---|
| 单独按 Shift | 中英切换（在微信输入法内部切换，不会切到别的输入法） |
| Shift+字母 / CapsLock | 中文模式下带大写字母的输入按英文处理：词库里的英文词按你输入的大小写给出（如 `BevF` → BevFusion），没有匹配就原样上屏 |
| Ctrl+Space | Fcitx5 自己的快捷键，默认在微信拼音和英文键盘之间切换 |
| `-` `=` / 方向键 / PgUp PgDn | 翻页（支持在配置中自定义） |
| 数字键 | 选择候选 |

- 候选翻页键：
  - 默认上一页为 `-`、小键盘 `-`、`Up`、`PageUp`；下一页为 `=`、`+`、小键盘 `+`、`Down`、`PageDown`。
  - 支持在 `fcitx5-configtool`（微信拼音 -> 配置）图形设置中或 `~/.config/fcitx5/conf/wetype.conf` 中自定义 `PrevPage` 与 `NextPage`（例如设为逗号/句号 `, .` 或方括号 `[ ]` 等）。
- 常用语：
  - 文字类：输入官方客户端里设的编码；没设编码的，输入前三个字的拼音首字母。常用语会出现在候选第一位。
  - 号码类（如电话、证件号）：直接输入开头几位数字，数字照常上屏，同时弹出常用语，按回车补全剩下的部分；Esc 关闭。
- 常见英文词（如 Linux、Python）引擎自带大小写；你自己打出来、被学进词库的英文词存成小写。全用小写输入时，这类词候选也是小写；需要大写时，输入里带上大写字母即可。
- 每页候选数跟随 Fcitx5 的全局设置。
- 中文模式下默认输出中文标点，数字里的小数点保持英文。在 Fcitx5 设置的“微信拼音”配置里勾选“始终使用英文标点”，即可继续输入中文，同时使用 `, . ! ? : ; ' " ( ) [ ]` 等英文标点；设置保存后立即生效，并在重启后保留。取消勾选恢复中文标点。
- 勾选后，组词时按标点仍会上屏当前候选并附加英文标点，如 `nihao` 后按 `,` 得到 `你好,`。自定义或默认的翻页键在组词时仍优先用于翻页。

## 4. 查看状态、停用、卸载

```sh
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py status    # 查看状态
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py disable   # 关闭云功能及剪贴板同步，保留身份和词库
./WeTypeIME-Engine-x86_64.AppImage uninstall --user              # 卸载，保留词库和身份
```

## 5. 运行测试

以下测试不需要账号，也不会访问官方服务器：

```sh
cmake -S fcitx5-wetype -B build && cmake --build build && ctest --test-dir build --output-on-failure
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/test_bionic_daemon.py --engine-dir ~/.local/lib/wetype-ime/arm64 --idle-seconds 85
```

已安装引擎并有 `python3-dbus`、`python3-gi` 时，可在私有 D-Bus 会话检查英文标点设置。测试使用临时配置和词库，不改桌面输入法或个人词库：

```sh
WETYPE_HARNESS_LOG="$(mktemp /tmp/wetype-punctuation-log.XXXXXX)" \
WETYPE_E2E_SCRIPT="$PWD/fcitx5-wetype/e2e/english_punctuation_test.py" \
bash fcitx5-wetype/e2e/run_paging_e2e.sh
```

小鹤双拼的集成检查使用临时词库：

```sh
python3 scripts/test_double_pinyin.py --engine-dir ~/.local/lib/wetype-ime/arm64
```

编译后可用 `--harness` 指定新的宿主程序。`--mode fcitx --addon-prefix 安装前缀`
在私有 D-Bus 会话中验证配置、候选和上屏，另需 `dbus-python`、`PyGObject` 与
`dbus-run-session`；前缀下需有 `share/fcitx5` 插件注册文件，插件库必须可被 Fcitx 找到。
可附加 `--cloud-launcher`，用关闭联网的临时云配置验证云代理启动分支。

最后一项全拼自检会启动已安装的引擎，测试输入、选词、学习和重启；它使用临时词库，不会改动你的个人词库。

## 常见问题

- **云候选或同步没反应**：先运行 `status` 检查状态，再检查网络和代理。网络请求不读取 `http_proxy` 等代理环境变量，需要能直连官方服务器，或者使用系统级 TUN 代理。
- **云结果到达后仍没显示**：云候选有效期默认 1500ms；可在 `~/.config/wetype-ime/cloud.json` 中设置 `cloud_timeout_ms`（200–5000 的整数），重启引擎后生效。本地候选不等待云请求完成。
- **远程桌面里长按退格只删一个字**：这取决于远程软件是否转发按键重复，不是输入法的问题。
- **报告问题**：请附上发行版、桌面环境、Fcitx5 版本和复现步骤。不要上传 `account` 目录、词库或 `harness.log`（日志里可能有输入内容）。
