# 语音输入

按住一个键说话，说话时文字陆续出现在输入框里，松开后最终结果上屏。识别由微信输入法官方服务器完成，效果和手机上的语音输入一致，带标点。

## 会发送什么

只有按住语音键的这段时间会打开麦克风，录音经 Opus 编码后发给微信输入法服务器识别。不发送光标前后的文字、最近发出的消息或当前应用名称；录音、识别文字和服务器响应都不保存到磁盘。

## 准备

1. 先[关联手机或 Mac](安装与使用.md#2-关联手机或电脑可选)。语音识别复用关联时生成的设备身份，不需要启用云候选。
2. 安装 Opus 编码库和录音程序（PipeWire 的 `pw-record`、PulseAudio 的 `parecord` 或 ALSA 的 `arecord`，有一个即可）：

   ```sh
   sudo apt install libopus0 pipewire-bin     # Ubuntu；PulseAudio 桌面装 pulseaudio-utils
   sudo pacman -S opus pipewire               # Arch
   ```

3. 打开 `fcitx5-configtool`，在“微信拼音”的配置里设置“语音输入快捷键”。推荐右 Ctrl 这类单独按下时没有作用的键，在设置框里按一下它即可。设置保存后立即生效，不需要重启 Fcitx5。清空这个按键就关闭语音输入。

也可以直接编辑 `~/.config/fcitx5/conf/wetype.conf`（编辑前先退出 Fcitx5）：

```ini
[VoiceInputKey]
0=Control_R
```

## 使用

| 操作 | 结果 |
|---|---|
| 按住语音键 | 开始录音，候选窗显示“请说话”和音量波形 |
| 说话 | 识别中的文字以带下划线的预编辑显示在输入框里，边说边更新（应用不支持预编辑时显示在候选窗） |
| 松开 | 停止录音，候选窗显示“识别中…”，最终结果随即上屏 |
| 松开后按 Esc | 放弃这次结果 |
| 松开后直接打字 | 先把已识别的文字上屏，再照常处理按键 |
| 按住时又按了别的键 | 当作组合键（如右 Ctrl+C），放弃这次语音，按键照常交给应用 |

- 按住不到 0.3 秒视为误触，不识别。
- 一次最长 60 秒，到时自动结束并上屏，之后再松开不会有额外动作。
- 正在拼写拼音时按语音键不会开始录音，按键照常处理；密码框里不录音。
- 中文和英文模式下都能用。

## 命令行

不经过 Fcitx5，直接识别一段录音或麦克风：

```sh
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py voice --wav 录音.wav   # 16kHz、单声道、16 位
python3 ~/.local/lib/wetype-ime/arm64/wetype-cloud.py voice --record 5      # 从麦克风录 5 秒
```

识别过程中逐行打印中间结果，最后输出一行 JSON。其他格式的录音可先用 `ffmpeg -i 输入 -ar 16000 -ac 1 -sample_fmt s16 输出.wav` 转换。

## 常见问题

| 提示 | 处理 |
|---|---|
| 尚未关联手机或 Mac | 按[关联手机或电脑](安装与使用.md#2-关联手机或电脑可选)关联后再试 |
| 找不到录音程序 | 安装 `pipewire-bin`、`pulseaudio-utils` 或 `alsa-utils` 中的一个 |
| 缺少 libopus | 安装 `libopus0`（Ubuntu）或 `opus`（Arch） |
| 网络超时、网络连接失败 | 网络要能直连 `wetype.weixin.qq.com`；和云候选一样不读 `http_proxy` |
| 没有听清 | 检查系统设置里的默认输入设备和麦克风音量；可先用 `voice --record 5` 在终端里试 |
| 按住没反应 | 确认当前输入法是“微信拼音”，并且设置里的按键与实际按下的键一致（左右 Ctrl 是不同的键） |
